# Strata Builds

Design, data, structure — visualizations and digital products from D.C. Barletta.

## Structure

- `/` — Hub landing page, project showcase
- `/studio` — Strata Works portfolio (engineering, product, design)
- `/atlas` — Microsat Atlas (population genetics visualizer)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build & Deploy

```bash
npm run build
npm start
```

Deploy to Vercel via GitHub push to `main` branch.

---

Built with Next.js 14, React 18, TypeScript.
