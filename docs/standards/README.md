# STRATA Engineering Standards

Documentation for STRATA Builds scientific and engineering standards.

## Documents

- **SCIENTIFIC-INTEGRITY-CHARTER.md** — Mandatory principles for all scientific work
  - Seven principles: Provenance, Transformations, Evidence Classification, Uncertainty, Reproducibility, Visual Clarity, Scientific Verification
  - Scientific Integrity Record template
  - Rules for AI-assisted scientific development
  - Checklist for scientific vs. visual changes
  - Required before merge to main

## Adoption Timeline

- **Stage A (Now):** Charter documented, templates created, guidance available
- **Stage B (After approval):** First application to NOAA Signals Lab (Listening Station)
- **Stage B+ (Future):** Every instrument (Deep Time, Orbital, Atlas) requires Scientific Integrity Record
- **Production gate:** Charter becomes mandatory CI requirement (timeline TBD by Fleet Command)
